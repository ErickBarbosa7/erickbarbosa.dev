# Planeación: Portafolio Web (Single Page Application)

## 1. Visión General
El objetivo de este proyecto es construir un portafolio web moderno en formato de *Landing Page* (una sola página estructurada por secciones continuas). Actuará como carta de presentación para reclutadores, mostrando no solo tus capacidades técnicas, sino también tu progresión hacia la arquitectura de software y el liderazgo ágil.

## 2. Stack Tecnológico
- **Frontend:** React + Vite (excelente rendimiento y recarga ultrarrápida).
- **Estilos:** Tailwind CSS (maquetación ágil, consistente con tus desarrollos recientes).
- **Iconografía:** Lucide React (limpios, modernos y consistentes).
- **Animaciones:** Framer Motion (transiciones y efectos al hacer scroll).
- **Despliegue:** Vercel o Netlify.

## 3. Estructura de la Landing Page
1. **Hero Section:** Titular principal, subtítulo destacando tu rol como Full-Stack y estudiante de Ingeniería, más enlaces directos a GitHub, LinkedIn y un botón para descargar el CV.
2. **Sobre Mí:** Un breve texto sobre tu enfoque académico, interés por sistemas ERP, infraestructura en la nube y automatización (n8n).
3. **Experiencia y Liderazgo:** Espacio enfocado en destacar el rol de Planning Manager y la gestión de sprints, además de la participación en eventos contra reloj (Hackathon).
4. **Proyectos Clave:** Grid interactivo. Cada proyecto (Kyro System, Nestly, StudyHub, Meraki) tendrá una captura de pantalla, descripción de retos resueltos, stack utilizado y enlaces.
5. **Habilidades Técnicas:** Una sección visual agrupando tecnologías por área (Frontend, Backend, Bases de Datos, DevOps).
6. **Contacto:** Despedida con un llamado a la acción y un correo directo.
